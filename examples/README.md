# Beispielprojekte (Examples)

Fertige Beispielprojekte nach Schwierigkeitsgrad, inklusive aller Zwischendateien.

## Verzeichnisstruktur

```
examples/
├── 01-wuerfel-einstieg/       ⭐ ab 5 Jahre
│   ├── README.md              # Projektbeschreibung
│   ├── wuerfel.obj            # 3D-Modell (Blockbench-Äquivalent)
│   ├── wuerfel-unfolded.svg   # Entfalteter Bastelbogen
│   ├── wuerfel-final.svg      # Fertiger Bogen mit Laschen und Legende
│   ├── wuerfel-final.pdf      # Druckfertiges PDF
│   ├── wuerfel-final-preview.png  # Vorschau 150 dpi
│   └── wuerfel-augen-final.*  # Variante mit Würfelaugen (SVG, PDF, Vorschau)
│
├── 02-lkw-mittel/             ⭐⭐ ab 7 Jahre (Roadmap)
│   ├── README.md
│   ├── lkw-input.png          # Eingabebild für das KI-Modell
│   ├── lkw-raw.obj            # KI-generiertes Rohmodell
│   ├── lkw-simplified.obj     # Nach Decimation
│   ├── lkw-unfolded.svg       # Entfaltet
│   ├── lkw-final-seite1.svg   # Kabine
│   ├── lkw-final-seite2.svg   # Auflieger + Räder
│   └── lkw-final.pdf          # Druckfertig (2 Seiten)
│
├── 03-haus-fortgeschritten/   ⭐⭐⭐ ab 9 Jahre
│   └── README.md
│
└── 04-tier-komplex/           ⭐⭐⭐⭐ ab 11 Jahre
    └── README.md
```

## Eigene Projekte einreichen

Siehe [CONTRIBUTING.md](../CONTRIBUTING.md) für Details. Bitte dokumentiere:

- Zielgruppe und Schwierigkeitsgrad
- Verwendete Tools und Einstellungen (Decimate-Parameter, Laschengrösse)
- Alle Zwischendateien (.obj, .svg)
- Optional: Fotos vom gebauten Modell
